# Clase 1 – Java

Ejercicios básicos de Java: variables, tipos de datos y salida por consola.

| Archivo | Descripción |
|---|---|
| `Main.java` | Variables básicas (String, int, double, boolean) |
| `TarjetaPresentacion.java` | Tarjeta de presentación por consola |
| `EdadEnDias.java` | Cálculo de la edad en días |
| `ConversorMoneda.java` | Conversión de pesos chilenos a dólares |
| `Desafio.java` | Intercambio de valores entre variables |

## Ejecutar

```bash
java Main.java
```
